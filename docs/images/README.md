# Screenshots do projeto

Esta pasta deve conter as capturas de tela reais da aplicação, referenciadas
pelo `README.md` principal do repositório. Nenhuma imagem foi gerada
artificialmente — as capturas abaixo precisam ser produzidas manualmente a
partir da aplicação rodando localmente (`yarn start` no diretório
`frontend/`, com o backend em `http://localhost:8080`).

## Capturas sugeridas

- `home.png` — Página inicial (`/`), com a barra de navegação, o título
  "Projeto Final" e o botão "Acessar formulário".
- `formulario.png` — Página do formulário de currículo (`/Formulario`),
  mostrando os campos de dados pessoais, formação e experiência.
- `formulario-preenchido.png` (opcional) — O mesmo formulário com dados de
  exemplo preenchidos, ilustrando o fluxo de uso.

## Convenções

- Formato PNG, largura recomendada de 1280px.
- Nomeie os arquivos em minúsculas, sem espaços (use `-` como separador).
- Ao adicionar uma nova imagem, referencie-a no `README.md` da raiz do
  projeto com um `alt text` descritivo.
